# 🚀 CRAZY COUNTER — React + Vite

A modern and stylish counter application built using **React** and **Vite**.  
This project includes a beautiful UI, smooth interactions, and fast deployment with Vercel.

🌐 **Live Demo:**  
👉 https://aditya-crazy-counter.vercel.app/

---



## ✨ Features

- 🔢 Increase / Decrease the counter  
- 🔄 Reset the counter  
- ⚡ Super-fast development environment using **Vite**  
- 🎨 Modern, attractive UI (fully custom CSS)  
- 📱 Responsive layout  
- 🚀 Automatically deployed on **Vercel**

---

## 🛠️ Tech Stack

- **React JS**
- **Vite**
- **CSS**
- **JavaScript**
- **Vercel**
